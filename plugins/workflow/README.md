# workflow

Personal Claude Code workflow: Elephant-Goldfish design skills (design-discussion, write-spec,
goldfish-test, mean-review, context-hierarchy), writing skills (clear-writing, unslop-text), opt-in
guard hooks, and `/workflow:workflow-init`, which scaffolds a local issue tracker, rules and a guard
config into any git repo. See the README at the repository root for install, setup and configuration.
